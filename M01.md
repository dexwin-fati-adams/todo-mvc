 Implementation steps
Keep each step small and ordered.
1. Create the GitHub repository — I create a new repository named todo-mvc under the Dexwin organization: https://github.com/dexwin-tech-ltd/todo-mvc.git
2. Connect to the Dexwin environment — I connect using SSH: ssh fati.adams@eng.dexwin.net. SSH provides an encrypted connection to the remote environment.
3. Clone the repository — git clone https://github.com/dexwin-tech-ltd/todo-mvc.git
4. Enter the repository — cd todo-mvc
5. Create the M02 branch — git checkout -b chore/m02-repository-setup
6. Check the branch — git branch. I confirm that the active branch is * chore/m02-repository-setup
7. Check Node.js — node --version. This confirms that Node.js is installed.
8. Check pnpm — pnpm --version. This confirms that pnpm is installed.
9. Enter the local repository — cd ~/Desktop/todo-mvc
10. Initialize the root package — pnpm init. This creates package.json, which stores the root package information (name, version, scripts, dependencies, and development dependencies).
11. Create the workspace directories — apps/api (backend), apps/web (frontend), packages/contracts (shared types and schemas).
12. Create pnpm-workspace.yaml — I created it in the root directory and add the packages and allowBuilds configuration.
13. Configure the workspace packages — the packages section tells pnpm where apps/api, apps/web, and packages/contracts are located.
14. Configure allowBuilds — I add allowBuilds: esbuild: true so the esbuild dependency can run its build script when required.
15. Create the contracts package — cd packages/contracts, then pnpm init, which creates packages/contracts/package.json.
16. Create the contracts source directory — packages/contracts/src/, which will hold the shared types and schemas.
17. Add the shared contracts — I add the shared data definitions used by the API and web applications (types/, schemas/, index.ts). The exact contract files will follow the project requirements.
18. Create the root configuration files — tsconfig.json, eslint.config.js, .prettierrc, .gitignore, README.md
19. Install dependencies — from the repository root, I run pnpm install and check the terminal output for errors.
20. Verify the workspace — I verify that pnpm recognizes apps/api, apps/web, and packages/contracts, and that the required files and folders exist.
21. Check Git status — git status. I review the files that were created or changed.
22. Commit the setup — I commit the repository setup changes to chore/m02-repository-setup.
23. Push the branch — I push the branch to the Dexwin GitHub repository.
24. Create the Pull Request — I create the Pull Request for M02 repository setup.
