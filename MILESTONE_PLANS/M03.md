Acceptance criteria
The Drizzle schema matches the approved todo model.
The real migration is generated from the schema source.
Generated migration files are not hand-edited.
The database connection is injected.
Persisted rows are validated at the repository boundary.
The migration proof uses an isolated disposable PostgreSQL database.
The proof covers an empty database, schema objects, constraints, a write, and a read.
API and PostgreSQL can be started locally with the documented Docker command.
CI and all relevant local checks pass.
