Objective
What will this milestone achieve?
 Define the todo data model, initial migration, database boundary, and migration proof.

Included
•   Created the Todo table with Drizzle, defined its fields and what each field should contain.
•   Set up Drizzle Kit and the first migration.
•   Added Docker Compose.
•   Connected the app to PostgreSQL using DATABASE_URL.
•   Added the Todo types and Zod validation.
•   Created a place for the app to communicate with the database and handle errors.
•   Added the database schema and migrations.
•   Tested that everything installs, builds, and runs correctly.
•   Committed and pushed the changes.
Not included
•   Todo CRUD business logic or service layer.
•   API routes or HTTP handlers.
•   Authentication.
•   Frontend integration or UI.
Current repository evidence
What files, commands, or existing patterns did you inspect before making this plan?

Unexpected failures
Unexpected problems can come from Docker, the computer, the internet connection, or PostgreSQL/Drizzle. If something goes wrong, I will check the error, find the cause, fix it, and run the checks again before continuing.
