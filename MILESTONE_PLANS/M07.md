Contracts
Input
GET /todos
This request has no body and no query parameters. Every field the client sends, if any, is ignored.
Success
200 OK
[
   {
 	"id": "uuid",
 	"title": "string",
 	"completed": false,
 	"createdAt": "ISO-8601 timestamp",
 	"updatedAt": "ISO-8601 timestamp"
   }
 ]
Success means the server sends back a list. Each item in the list is one todo, in the same shape as the response from POST /todos.
Expected Failures
There are no client input failures for this endpoint, because the request has no body and no parameters to check.
Unexpected Failures
●      Example: the database is down, or the read query fails.
●      Example: a row from the database does not match the expected shape (for instance a missing field).
●      These are caught at the repository. They become Result.err({ type: "UnexpectedError", cause }). The error is logged. The client only sees a plain 500 message, with no internal details.
●      No error should ever escape without being caught. The route uses ts-pattern to handle every possible Result.
Responsibilities
Layer
What it does
Route
Calls the service. Turns the Result into an HTTP response. Has no business rules.
Service
Asks the repository for all todos. Passes the Result through, or wraps it if needed.
Repository
Runs the one SELECT on the todos table, using db.ts, ordered by createdAt. Checks that each row matches the expected shape. Catches any database error and turns it into UnexpectedError.
Hook
Not used. This milestone has no frontend.
View
Not used. This milestone has no frontend.
